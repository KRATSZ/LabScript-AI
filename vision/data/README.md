# Vision Data

This directory is the in-repo home for optional vision datasets and captures.

By default, git ignores the heavy, frequently changing parts:

- `camera-captures/`
- `datasets/`
- `raw_videos/`
- sample image exports under `frames/samples/`
- local prediction scratch folders

Keep only small, intentional source artifacts here, such as README files or hand-picked fixtures that are worth versioning.
