# Experiment-Type SOP

不同实验类型有不同的 SOP 关键点，agent 应主动应用：

## 细胞培养 (Cell Culture)

- Gentle aspiration — 避免从 bottom 直接吸
- Trypsin 后加 pause 让用户镜检
- Mix 体积不超过孔体积 50%

## PCR

- 注意试剂冰上保存
- Add template DNA 只加到指定孔
- Master mix 配制时注意 tip 预算

## ELISA

- Wash cycle 用循环结构
- 注意 tip 数量预算（多轮 wash 消耗大）

## DNA Extraction (Magnetic Beads)

- Bead resuspension — 充分混匀
- Magnetic module 分离 timing — 等待磁珠完全分离
- Wash buffer 多次循环 — 通常 2-3 次
