代码开发板

1. TUI 总框架

一句话：用户正常聊天先被分流，只有写协议、查机器人、恢复运行才进入工具系统。

关键点：聊天、状态、写协议都从同一个 TUI 入口进来，但只有需要工具时才走统一 agent 和 Gatekeeper。

2. HTTP 轮询唤醒

一句话：不是每轮都叫模型；先用规则看是否异常，异常才唤醒 agent。

关键点：event-driven 的第一版是 HTTP polling；正常变化不打扰模型，异常才叫醒它。

3. 核心 agent 引擎

一句话：核心不是 bash，而是一个会反复观察、调用工具、更新状态、写 trace 的 agent loop。

关键点：LabscriptAI 的核心不是 bash，而是一个会反复观察、调用工具、更新状态、写 trace 的 agent loop；skill 提供规则，memory 提供经验，所有动作先过 Gatekeeper。
